---
name: session-start
description: Load project state at the start of a working session. Use at the beginning of every session, before any code change.
---
1. Read docs/PROGRESS.md.
2. Run git status and git log --oneline -15.
3. In docs/plan/IMPLEMENTATION_PLAN.md, read the current milestone and any
   section the current task depends on.
4. If PROGRESS.md and git disagree, trust git, correct PROGRESS.md and say so.
5. State the task, the files you expect to touch and how you will verify it.
   Then begin.
